# Recipe Page

A responsive recipe page built as a Frontend Mentor challenge.

## Live site

[View the live site](https://effulgent-wisp-05e49e.netlify.app/)

## What I built

A recipe page for a simple omelette, with an image, a preparation time box, an ingredients list, numbered instructions and a nutrition table. The layout adapts to mobile screens with a media query.

## Built with

- Semantic HTML (headings, lists, table)
- CSS (custom fonts with @font-face, media query for mobile)

## What I learned

- How to structure a page with semantic HTML
- How to style it with CSS and match a design
- How to test the mobile view with browser DevTools

## What I would improve

- Use CSS variables for colors and fonts
- Try a mobile-first approach
